This is a project for the course DSC80 at UCSD.

# Do Danceable Tracks Perform Better on Spotify?

**By Evelyn Na**

## Introduction

This project investigates whether more danceable tracks tend to be more 
popular on Spotify, and whether this relationship varies across genres. 
Using a dataset of 114,000 Spotify tracks spanning 114 genres, we focus 
on five musically distinct genres: classical, hip-hop, metal, jazz, and pop.

**Research Question:** Do more danceable tracks tend to be more popular, 
and does this relationship vary across genres?

This question matters because Spotify's recommendation algorithms and 
playlist curators often rely on audio features - understanding which 
features correlate with popularity could reveal how listener behavior 
differs by genre.
